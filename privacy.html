隱私權政策

生效日期：2026 年 11 月 2 日 · 適用網站：https://boyuanliao.github.io/trainlog-pro/

TrainLog Pro 是由 GitHub Pages 提供的靜態健身紀錄網頁應用程式。本政策說明應用程式目前如何取得、使用、儲存及分享資料。使用 Google Drive 備份功能完全由你自行選擇，不使用該功能也能記錄訓練。

一、我們處理哪些資料

  • 你輸入的訓練資料，例如訓練日期、動作、重量、次數、課表、訓練目標、訓練偏好、健身房與器材、身體狀態及備份紀錄。
  • 操作偏好及應用程式設定，例如介面語言、單位和計時設定。
  • 選擇 Google Drive 備份時，瀏覽器會在你授權後取得 Google OAuth 存取權杖，用於上傳、列出及讀取本應用程式的雲端備份檔案。

二、資料的用途與儲存位置

  • 預設本機儲存：健身紀錄主要保存在你目前裝置與瀏覽器的 LocalStorage，用來顯示訓練紀錄、圖表、課表和使用者設定。不同裝置不會自動同步。
  • 你主動啟用的雲端備份：首次手動備份成功並啟用自動備份後，網站開啟且 Google 授權有效時，資料變更可於約 10 秒後自動上傳；應用程式會把完整的健身紀錄 JSON 上傳至你 Google 帳號的 Drive 隱藏應用程式資料空間 appDataFolder；一般的「我的雲端硬碟」列表不會直接顯示這類檔案。應用程式會嘗試保留最近 5 份備份。
  • 還原：你主動選擇恢復時，應用程式會下載雲端備份並顯示匯入預覽，在確認前不會直接覆蓋本機資料。
  • 權杖處理：為減少重新整理後重複授權，應用程式會暫時將 Google OAuth Access Token 與到期時間儲存於此瀏覽器的 LocalStorage，在到期或 Google API 回覆 401 時清除。這些資料可被同一網站來源的 JavaScript 存取，因此使用共用裝置或遭遇惡意腳本時有憑證風險。應用程式不儲存 Refresh Token、Google 密碼或 Client Secret；到期後仍需重新授權。你也可透過清除本網站的瀏覽器儲存資料刪除暫存權杖。

三、Google 資料存取權限與用途限制

本應用程式僅請求 https://www.googleapis.com/auth/drive.appdata 權限，以建立、查詢、讀取及刪除 TrainLog Pro 在 Google Drive 專用應用程式資料空間中的備份檔案，不要求一般雲端硬碟檔案的全面存取權限。

從 Google API 取得的資料僅用於提供使用者要求的備份與恢復功能，不會出售、用於廣告投放或向資料仲介提供。除執行使用者明確要求的功能、遵守法律及維護安全所必要的情況外，不會轉移 Google 使用者資料予第三方，也不會供人員任意讀取。資料使用方式遵守 Google API Services User Data Policy（包含適用的 Limited Use 規定）。

四、外部服務

本網站使用 GitHub Pages 提供靜態網頁，並可載入 GitHub 上的第三方 Exercise Library 動作示範素材；選擇雲端備份時會連接 Google Identity Services 與 Google Drive API。這些服務提供者可能依各自政策處理必要的連線資訊，例如 IP 位址、瀏覽器與請求記錄；TrainLog Pro 不控制其獨立處理行為。

五、Google Analytics 網站使用情況分析

本站首頁使用 Google Analytics 4（GA4，評估 ID：G-5JY343RVLX），以了解網站瀏覽量、流量來源及一般使用情況，協助維護服務。載入 Google 標籤後，Google 可能透過 Cookie 或其他線上識別資訊、頁面瀏覽事件、瀏覽器與裝置資訊及連線資訊處理資料。實際收集範圍亦受 Google Analytics 的資料串流與加強型評估設定影響。Google Analytics 不會由本站主動傳送你的訓練重量、次數、課表內容或完整備份 JSON；請勿在網址中放置敏感資料。

Google 可能依其 隱私權政策 處理相關資訊。你可透過瀏覽器 Cookie 或追蹤保護設定限制追蹤，也可使用 Google Analytics 停用瀏覽器外掛程式（若適用）。目前 GA4 標籤在首頁載入時即啟動，並非待使用者單獨同意後才啟用；若適用法令要求另行取得同意，網站管理者應先完成相應同意管理機制。

六、資料保留、刪除與撤銷權限

  • 你可在 TrainLog Pro「設定 → 資料與備份」匯出完整 JSON 備份，或清除目前瀏覽器內的訓練資料。清除本機資料不會自動刪除 Google Drive 已有的備份。
  • Google Drive 備份由你的 Google 帳號保存；應用程式會在後續成功備份時嘗試移除超過最近 5 份的舊備份，操作失敗時可能暫時保留更多份。
  • 你可以在 Google 帳號的第三方應用程式存取權設定撤銷 TrainLog Pro 的 Google 存取權。撤銷授權本身不等同於清除瀏覽器內的資料或立即刪除所有已建立的備份。若需完全刪除雲端備份，可透過 Google Drive 應用程式資料管理功能處理，或透過下方聯絡管道請求協助。

七、安全性與限制

本站經 HTTPS 傳送網頁及 Google API 請求；但本機瀏覽器資料不等於經過端對端加密的保管箱。共用電腦、瀏覽器清除資料、裝置遺失、第三方服務故障或同步衝突均可能影響資料安全。建議定期下載一份完整 JSON 備份保存在你信任的位置。

八、政策更新及聯絡

如新增雲端同步、分析服務或變更資料處理用途，會更新本政策並標示新日期。對資料處理、刪除或本政策有問題，可透過 TrainLog Pro GitHub Issues 聯絡專案維護者；請勿在公開 Issue 中張貼個人訓練紀錄、Google 存取權杖或其他敏感資料。
