# docs/

此目錄保存「如何理解與維護 TrainLog Pro」的工程文件，不放執行時程式碼。

## 文件

### `REFACTOR.md`
重構主追蹤文件。記錄：
- 為什麼拆
- 拆分順序
- 哪些已完成 / 尚未完成
- 每一階段驗證要求
- 已知技術債

下次若要繼續重構，請先讀根目錄 `README.md`、`js/README.md`，再讀 `REFACTOR.md`。

## 文件維護規則

當模組實際搬移完成後，必須同步更新：
1. 對應目錄 README
2. `REFACTOR.md` checkbox / 狀態
3. 根目錄 README 的架構圖（如果載入結構改變）

不要讓文件描述「預定架構」卻看起來像「已完成架構」；尚未搬移的內容必須明確標註為重構骨架。
